## Description

# Model Summary

This model is a VotingClassifier that combines linguistic features from GPT-2 language models, open-sourced by openai, to detect whether a given text was written by a human or generated by a large language model (LLM). The key features used are perplexity (PPL) and Giant Language Model Test Room (GLTR) statistics, which measure how well the text conforms to common language patterns and structures learned by the GPT-2 models during training. The model was trained on an [starblasters8/human-vs-llm-text-corpus](https://www.kaggle.com/datasets/starblasters8/human-vs-llm-text-corpus) and achieved an ROC AUC score of 0.956 on the private leaderboard of the competition.

## Usage

``` python
import torch
import joblib

import numpy as np
import pandas as pd
import gradio as gr

from nltk.data import load as nltk_load
from transformers import AutoTokenizer, AutoModelForCausalLM


print("Loading model & Tokenizer...")
model_id  = 'openai-community/{}' # one of ['gpt2', 'gpt2-medium', 'gpt2-large']
tokenizer = AutoTokenizer.from_pretrained(model_id)
model     = AutoModelForCausalLM.from_pretrained(model_id)

print("Loading NLTL & and scikit-learn model...")
NLTK = nltk_load('data/english.pickle')
sent_cut_en = NLTK.tokenize
clf = joblib.load(f'data/gpt2-small-model')

CROSS_ENTROPY = torch.nn.CrossEntropyLoss(reduction='none')

def gpt2_features(text, tokenizer, model, sent_cut):
    # Tokenize
    input_max_length = tokenizer.model_max_length - 2
    token_ids, offsets = list(), list()
    sentences = sent_cut(text)
    for s in sentences:
        tokens = tokenizer.tokenize(s)
        ids = tokenizer.convert_tokens_to_ids(tokens)
        difference = len(token_ids) + len(ids) - input_max_length
        if difference &gt; 0:
            ids = ids[:-difference]
        offsets.append((len(token_ids), len(token_ids) + len(ids)))
        token_ids.extend(ids)
        if difference &gt;= 0:
            break

    input_ids = torch.tensor([tokenizer.bos_token_id] + token_ids)
    logits = model(input_ids).logits
    # Shift so that n-1 predict n
    shift_logits = logits[:-1].contiguous()
    shift_target = input_ids[1:].contiguous()
    loss = CROSS_ENTROPY(shift_logits, shift_target)

    all_probs = torch.softmax(shift_logits, dim=-1)
    sorted_ids = torch.argsort(all_probs, dim=-1, descending=True)  # stable=True
    expanded_tokens = shift_target.unsqueeze(-1).expand_as(sorted_ids)
    indices = torch.where(sorted_ids == expanded_tokens)
    rank = indices[-1]
    counter = [
        rank &lt; 10,
        (rank &gt;= 10) & (rank &lt; 100),
        (rank &gt;= 100) & (rank &lt; 1000),
        rank &gt;= 1000
    ]
    counter = [c.long().sum(-1).item() for c in counter]


    # compute different-level ppl
    text_ppl = loss.mean().exp().item()
    sent_ppl = list()
    for start, end in offsets:
        nll = loss[start: end].sum() / (end - start)
        sent_ppl.append(nll.exp().item())
    max_sent_ppl = max(sent_ppl)
    sent_ppl_avg = sum(sent_ppl) / len(sent_ppl)
    if len(sent_ppl) &gt; 1:
        sent_ppl_std = torch.std(torch.tensor(sent_ppl)).item()
    else:
        sent_ppl_std = 0

    mask = torch.tensor([1] * loss.size(0))
    step_ppl = loss.cumsum(dim=-1).div(mask.cumsum(dim=-1)).exp()
    max_step_ppl = step_ppl.max(dim=-1)[0].item()
    step_ppl_avg = step_ppl.sum(dim=-1).div(loss.size(0)).item()
    if step_ppl.size(0) &gt; 1:
        step_ppl_std = step_ppl.std().item()
    else:
        step_ppl_std = 0
    ppls = [
        text_ppl, max_sent_ppl, sent_ppl_avg, sent_ppl_std,
        max_step_ppl, step_ppl_avg, step_ppl_std
    ]
    return ppls + counter  # type: ignore


def predict_out(features, classifier, id_to_label):
    x = np.asarray([features])
    pred = classifier.predict(x)[0]
    prob = classifier.predict_proba(x)[0, pred]
    return [id_to_label[pred], prob]


def predict(text):
    with torch.no_grad():
        feats = gpt2_features(text, tokenizer, model, sent_cut_en)
    out = predict_out(feats, clf, ['Human Written', 'LLM Generated'])
    return out

predict('Hello there!')
```

## System

This is a standalone model that takes a text input and outputs a binary prediction. It requires the pre-trained GPT-2 models and the trained VotingClassifier to be loaded before making predictions. There are no downstream dependencies when using the model outputs.

## Implementation requirements

The model was trained using Python and the scikit-learn library for the VotingClassifier. The pre-trained GPT-2 models were loaded using the Hugging Face Transformers library. The training of the VotingClassifier was done on CPU, therefore inference is lightning fast even on CPU. However, the extraction of GPT-2 features were done on GPU, but this can be done on CPU too.

# Model Characteristics

## Model initialization

The VotingClassifier was trained from scratch using the PPL and GLTR features computed from the pre-trained GPT-2 models (small, medium, and large).

## Model stats

The size of the VotingClassifier itself is small, but it relies on the pre-trained GPT-2 models for feature extraction, which have the following sizes:

- GPT-2 Small: 124M parameters
- GPT-2 Medium: 355M parameters
- GPT-2 Large: 774M parameters

## Other details

The model is not pruned or quantized. No techniques were used to preserve differential privacy.

# Data Overview

## Training data

The model was trained on [starblasters8/human-vs-llm-text-corpus](https://www.kaggle.com/datasets/starblasters8/human-vs-llm-text-corpus). The dataset consists of 800,000 text samples labeled as either human-written or LLM-generated. No specific pre-processing was done

## Evaluation data

The model was trained on the entire dataset and tested on the hidden test set from the competition

# Evaluation Results

The model achieved an ROC AUC score of 0.938 on the public leaderboard and 0.956 on the private leaderboard of the competition. These results can be viewed on the [leaderboard page](https://www.kaggle.com/competitions/llm-detect-ai-generated-text/leaderboard)
