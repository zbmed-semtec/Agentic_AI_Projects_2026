## Description

# Model Summary

You can use this model to detect Events at football matches, it is trained to detect: Dribbles, Tackles, Duels, Injuries, Goal and goal line.

## Note
&gt;These Events are detected as objects and then you can use trackers and algorithms to track events and extract the real goal and line points, you will find a usage example in TACTIC-ZONE notebook.

## Usage

use this model with Eagle Eye matches feed and mix it with TACTIC-ZONE algorithms, then the sky is your limit

## System

this is a YOLOv8x model, you can use it with ULTRALYTICS libs to get use of YOLO features.
